## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FOA PDF → Parser | User-uploaded PDFs (potentially malicious) |
| LLM Output → Pydantic | Untrusted structured output from local LLM |
| Ollama API → Client | Local service, but network boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Tampering | Malicious PDF content | high | mitigate | PyMuPDF sandboxed; size limit (50MB); timeout on extraction |
| T-01-05 | Spoofing | LLM prompt injection in FOA text | high | mitigate | Delimiter-based prompts; sanitize input; Pydantic validation on output |
| T-01-06 | Information Disclosure | Model extraction via parser | low | accept | Local-only Ollama; no external API |
| T-01-07 | Denial of Service | Large PDF / infinite LLM loop | medium | mitigate | Page limit (200 pages); token limit on LLM calls; async timeouts |
| T-01-SC | Tampering | pip install dependencies | high | mitigate | Package legitimacy gate; requirements pinned |

</threat_model>
