## Project Overview

**Grant Writing AI** — Autonomous grant writing pipeline for NIH R01 applications. Reduces 6 weeks of professor time to 4 hours using a local, zero-cost multi-agent system: Planner → Retriever → Drafter → Critic → Formatter. PIs interact via React web UI. Target: working prototype in 1 week for 2-3 co-design PI partners.

**Core Value:** End-to-end R01 draft generation (Specific Aims, Research Strategy, Biosketches, Budget) with compliance validation — all local, all free, human-in-the-loop at decision points.

**Stack:** Python 3.11+ (LangGraph, ChromaDB, Ollama, python-docx) + React 18/TypeScript/Vite (use-local-llm). Models: Llama-3.1-8B-Instruct-Q4_K_M primary.

## Development Guidelines

### Python Agents
- Use **LangGraph** for agent orchestration (state machine with human gates)
- **Pydantic** models for all data structures (ApplicationPlan, SectionDraft, ValidationReport)
- **Ollama** via `ollama` Python package (OpenAI-compatible API)
- **ChromaDB** for vector store; `sentence-transformers` for embeddings
- **python-docx** for DOCX generation; **PyMuPDF**/**pdfplumber** for PDF parsing
- **Ruff** for linting/formatting; **pytest** for testing

### React UI
- **Vite + React 18 + TypeScript** + **Tailwind CSS**
- **use-local-llm** hooks for streaming from Ollama
- **Polling/WebSocket** for long-running pipeline progress
- **Structured forms** at human gates (not free text) to preserve structure

### Git Workflow
- `agent/drafts` branch: auto-commits per agent pass
- `pi/edits` branch: PI gate commits
- `main` branch: approved milestones
- Commit messages: `type(scope): message` with REQ-IDs, agent, model, chunks

## Critical Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Local LLM quality for 12-page Strategy | Section-by-section + few-shot from PI grants + 2-3 Drafter↔Critic iterations |
| FOA compliance variability | FOA parser → YAML config (externalized, not hardcoded) |
| RAG relevance for niche domains | Hybrid search (BM25 + vector) + PI manual tagging + show chunks in UI |
| Anonymization failures | Multi-layer (regex + spaCy NER) + PI review UI + audit log |
